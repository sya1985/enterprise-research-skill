# enterprise-research-skill
enterprise-research 是一个企业全维度背调技能：
做什么：输入企业名称 → 自动查询工商/财务/行业/待遇/岗位信息 → 生成 MD 报告 + HTML 对比看板。

7 步工作流程：

步骤	内容	数据来源
①	确认企业全称	—
②	工商登记、财务、股权、年报、分支机构	企查查 Connector（需要企查查 Connector，如果没有或者断开，降级为网络搜索）
③	行业前景、竞争格局、市场规模	网络搜索
④	员工评价、加班/双休、薪资待遇（默认聚焦研发岗）	脉脉/看准网/BOSS直聘等
⑤	地域岗位补充（默认杭州 测试&测开）	招聘平台搜索
⑥	8 维度评分（发展前景/稳定性/薪资/工作生活平衡/福利/技术成长/岗位匹配度/规模）	基于前五步数据
⑦	输出 MD 报告 + 累积式 HTML 对比看板	—
核心原则：实事求是，查不到就标"查不到"，绝不编造。

当前局限：第二步的企查查 Connector 一直处于断开状态，工商/财务等权威结构化数据无法获取，所有信息靠网络搜索拼凑，数据精确度打折扣。

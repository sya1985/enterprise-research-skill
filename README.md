# enterprise-research-skill
enterprise-research 是一个企业全维度背调技能。当你找工作想要更全面了解一个企业，可以对它进行一个简单的背调。

### 做什么
输入企业名称 → 自动查询工商/财务/行业/待遇/岗位信息 → 生成 MD 报告 + HTML 对比看板。

7步工作流程：

| 步骤  | 内容                                                         | 数据来源                                               |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------ |
| ①    | 确认企业全称                                                 | —                                                      |
| ②    | 工商登记、财务、股权、年报、分支机构                         | 需要企查查 Connector，如果没有或者断开，降级为网络搜索 |
| ③    | 行业前景、竞争格局、市场规模                                 | 网络搜索                                               |
| ④    | 工评价、加班/双休、薪资待遇（默认聚焦研发岗）                | 脉脉/看准网/BOSS直聘等                                 |
| ⑤    | 地域岗位补充（默认杭州 测试&测开）                           | 招聘平台搜索                                           |
| ⑥    | 8 维度评分（发展前景/稳定性/薪资/工作生活平衡/福利/技术成长/岗位匹配度/规模） | 基于前五步数据                                         |
| ⑦    | 输出 MD 报告 + 累积式 HTML 对比看板                          | —                                                      |


### 核心原则
实事求是，查不到就标"查不到"，绝不编造。

### 前置依赖
**qcc-company 技能**：企查查 Connector，获取工商/财务/年报等权威数据。如果一直处于断开状态，工商/财务等权威结构化数据无法获取，所有信息靠网络搜索拼凑，数据精确度打折扣。


### 企业背调报告
- **基本信息**：工商登记、注册资本、成立日期、法定代表人、股权结构
- **行业信息**：行业前景、竞争格局、市场份额
- **财务数据**：营收、净利润、年报数据（如有公示）
- **员工评价**：薪资待遇、工作强度、工作生活平衡、技术成长
- **地域岗位**：指定城市的测试/测开岗位招聘情况
- **多维评分**：8 个维度 0-10 评分（发展前景、稳定性、薪资竞争力、工作生活平衡、福利完善度、技术成长性、岗位匹配度、公司规模）

### 企业多维对比看板
每次背调一家企业，会在企业多维对比看板上自动新增一条数据，也可以手动新增或者删除数据。

### 使用方式
#### 安装
下载WorkBuddy
https://www.codebuddy.cn/events/invite?inviteCode=acjtmw4jtix2rv
> 编写和测试用的都是腾讯的WorkBuddy，其他像扣子、openClaw、 Claude Code应该也能用。

```bash
# 克隆到 WorkBuddy 技能目录
git clone <repo-url> ~/.workbuddy/skills/enterprise-research/
```
或手动下载后放入 `~/.workbuddy/skills/enterprise-research/`。


#### 使用
在 WorkBuddy 对话中输入：
```
@skill:enterprise-research 企业名称 [城市][岗位]
```
示例：
```
@skill:enterprise-research 阿里巴巴 杭州
@skill:enterprise-research 字节跳动 上海 AI算法
```
默认查询城市为杭州，测试/测开岗位。

#### 输出
每次调研生成：
1. `企业名称_调研报告.md` — Markdown 格式完整报告
2. 自动更新 `企业对比看板.html` — 多企业雷达图/柱状图对比看板

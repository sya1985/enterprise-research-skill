# enterprise-research-skill
enterprise-research 是一个企业全维度背调技能。当你找工作想要更全面了解一个企业，可以对它进行一个简单的背调。

**做什么**：输入企业名称 → 自动查询工商/财务/行业/待遇/岗位信息 → 生成 MD 报告 + HTML 对比看板。

7 步工作流程：

| 步骤 | 内容                                                         | 数据来源                                               |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------ |
| ①    | 确认企业全称                                                 | —                                                      |
| ②    | 工商登记、财务、股权、年报、分支机构                         | 需要企查查 Connector，如果没有或者断开，降级为网络搜索 |
| ③    | 行业前景、竞争格局、市场规模                                 | 网络搜索                                               |
| ④    | 工评价、加班/双休、薪资待遇（默认聚焦研发岗）                | 脉脉/看准网/BOSS直聘等                                 |
| ⑤    | 地域岗位补充（默认杭州 测试&测开）                           | 招聘平台搜索                                           |
| ⑥    | 8 维度评分（发展前景/稳定性/薪资/工作生活平衡/福利/技术成长/岗位匹配度/规模） | 基于前五步数据                                         |
| ⑦    | 输出 MD 报告 + 累积式 HTML 对比看板                          | —                                                      |


**核心原则**：实事求是，查不到就标"查不到"，绝不编造。

**当前局限**：第二步的企查查的MCP如果一直处于断开状态，工商/财务等权威结构化数据无法获取，所有信息靠网络搜索拼凑，数据精确度打折扣。

**企业背调报告**
包括基本信息、行业信息、待遇情况、岗位补充信息、企业多维评分几部分组成

**使用方式**
- 编写和测试用的都是腾讯的WorkBuddy，其他像扣子、openClaw、 Claude Code应该也能用。
- 安装完skill后，直接在对话中说出企业名称即可触发，例如：「帮我查一下XX公司」「查企业XX」。技能会自动执行上述 7 步流程并生成报告
- 第四步待遇情况，如果存在多岗位多工种的情况，没有告知查询具体岗位的情况下，默认研发岗（排除行政岗、产线岗）
- 第五步地域岗位补充信息，如果没有告知具体就业地点和具体岗位，默认杭州（测试 & 测开岗位），如果有查询输入，以实际查询输入为准，以后查企业时说「帮我查XX公司」→ 自动走杭州测试岗；说「查XX公司 北京 后端开发」→ 按北京后端开发搜。
  - 未指定 → 默认杭州的测试 & 测开
  - 有输入 → 以实际输入为准（如「北京 开发」「深圳 AI算法」）

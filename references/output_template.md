# 企业调研报告输出模板

> 以下为报告输出的 Markdown 模板。将各步骤获取的数据填入对应位置，生成最终报告文件。
> `{{}}` 标记为占位符，替换为实际数据。查不到的字段填写"查不到"。

---

## 模板内容

```markdown
# {{企业名称}} 企业调研报告

> 报告生成日期：{{YYYY-MM-DD}}
> 数据来源：企查查（工商/财务数据）、网络公开信息（行业分析/员工评价等）
> 声明：本报告基于公开数据整理，信息仅供参考。财务数据可能存在公示滞后，员工评价具有主观性。

---

| 成立日期 | {{成立日期}} |
| 注册资本 | {{注册资本}} |

### 融资情况
```
